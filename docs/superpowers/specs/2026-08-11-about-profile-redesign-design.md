# 关于光泰公司简介页重设计

## 背景

现有“关于光泰”将完整公司简介作为能力切换器首项的大标题，桌面端形成左侧编号分栏与右侧超大长标题，阅读层级失衡。用户明确要求移除该页左侧分栏，并参考成熟科技企业官网的公司简介页重新组织内容。

## 目标

- 保留顶部“关于光泰”Hero、页内导航、交付路径、相关页面和项目联系入口。
- “关于光泰”使用专属静态简介组件，其他页面继续使用现有能力切换器。
- 正文采用企业官网常见的短标题、可读段落、事实概览和能力卡片结构。
- 不新增未经确认的规模、客户、资质、专利或营收数据。

## 页面结构

1. **公司简介**：使用 `01 / COMPANY PROFILE` 眉题和短标题“让技术能力真正进入业务现场”。正式简介拆为导语与正文，正文最大阅读宽度约 820px。
2. **企业概览**：展示“2013 / 成立时间”“天津 / 集团总部”“全流程 / 交付能力”“多行业 / 服务场景”，全部来自现有正式简介。
3. **核心能力**：四项能力改为双列静态卡片，使用编号、标题和简短说明，不使用 Tab、hover 切换或移动端折叠器。
4. **交付与联系**：继续复用现有紧凑交付路径、相关页面和项目联系组件。

## 响应式与可访问性

- 桌面端概览四列、能力卡双列；小屏概览双列、能力卡单列。
- 正文保持 1.75–1.9 行高，长段落不采用超大字号。
- 页面保持顺序标题层级：Hero `h1`、简介/能力 `h2`、能力卡 `h3`。
- 静态内容不伪装成交互控件；移除关于页上的 `tablist`、`tabpanel` 和移动端折叠按钮。
- 保留 `data-reveal`，继续复用全站减少动态效果与路由生命周期。

## 验收标准

- 1440px 下不再出现左侧“定位与价值”编号分栏，简介短标题不超过两行，正文使用正常阅读字号。
- 390px 下无横向溢出，企业概览为两列，能力卡为单列。
- 关于页包含四项事实概览和四张能力卡；其他页面的能力切换器行为不变。
- Astro 检查、单元测试、构建、静态渲染测试和相关 Playwright 回归通过。
